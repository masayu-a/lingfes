# 言語学フェス2027｜www2向け JavaScript不使用・静的Webサイト

**国語研 `https://www2.ninjal.ac.jp/lingfes/` の配置用サンプルです。** 実際のURL開設・本番サーバーへの配置は、国語研の管理担当による承認と設定が必要です。現在、本パッケージはローカルファイルでありGitHubリポジトリへの登録・本番公開はしていません。

## 過年度プログラム（タイトル保全）

- **2021〜2026年、計483件の発表番号・題名を収録**。データは `data/archive_titles_2021-2026.json`、読みやすい一覧は `docs/lingfes_titles_2021-2026.md`。
- `scripts/build_site.py` を実行すると、`public/2021/` 〜 `public/2026/` の題名一覧HTMLが再生成されます。www2側ではJavaScriptを使いません。
- 原典URLは各年度のページに記載。**転記誤りの最終照合は未了**です。2021年は原典42タイトルに対し、開催報告で「44件」と記載されているため、差分を未確認として明記しています。
- 2027年の発表枠とは独立した記録です。過年度のPDF、著者や参加者の連絡先は保存していません。

## 重要な仕様

- **www2サーバーへはHTML/CSSのみを配置。JavaScriptファイルも `<script>` タグも一切使用しません。** クライアントの `fetch()` や動的JSON読込も行いません。
- **GitHub上で編集**するのは `src/`（HTML・CSS）と `data/`（JSON）。GitHub Actionsまたは手元のPythonで **公開前に** 静的HTMLを生成します。www2はPythonやJSONを実行・配信しません。
- 発表地図は **A/B/C それぞれ別HTML**（`2027/map-a.html`, `map-b.html`, `map-c.html`）。回の変更はただのリンク移動です。
- 発表一覧は `2027/program.html`（HTML本文に埋め込み）。キーワード検索機能はありません。ブラウザのページ内検索（Ctrl+F）を利用してください。
- 各ブースB01〜B36は、発表登録時に `program.html#A-B01` のような固定アンカーへリンクします。右下B29〜B36は国語研現地配信候補です。
- オンライン発表は **36件×3回＝最大108件**。うち国語研からの現地配信は延べ24件まで。2日目の現地ポスターは12件×3回＝最大36件（案）。
- 個別のサムネイル・発表証明書なし。公開同意のないPDFや応募名簿をこのサイトへ格納しないでください。

## ファイル構成

| --- | --- |
| `src/index.html` | 恒久トップ `/lingfes/` の公開原稿 |
| `src/2027/index.html` | 2027年の開催概要と募集要項。申込リンクは生成時に差込 |

| `scripts/validate_site.py` | ファイル・アンカー・禁止スクリプトを検査 |
| `public/` | **生成済み公開ファイル**。www2に置くのはこのディレクトリの中身だけ |

## GitHub のWeb画面から更新する場合

1. 年間の案内文を修正するには `src/2027/index.html` を開いて鉛筆アイコンから編集しコミット。
2. 申込URLを決めたら `data/site-2027.json` に **https:// ではじまる正式URL** を設定。未確定なら空欄のまま。
3. 発表プログラムは `data/program-2027.json` の `presentations` にエントリーを追加。書式例は `docs/program.sample.json`。募集時に集めたPDFはここにアップロードせず、公開許諾を得たURLのみ登録します。
4. `main` ブランチへの変更で GitHub Actions が `scripts/build_site.py` と `scripts/validate_site.py` を実行し、GitHub Pagesプレビュー（有効化した場合）にHTML/CSSのみ公開します。
5. **www2への反映は別工程**です。国語研側の承認を得た方法で生成済みの `public/` の中身のみを配置します。自動転送ワークフローは初期状態で無効です。

**注意：** GitHub Pagesとwww2のURLは別物です。GitHub PagesのCNAME設定だけで `www2.ninjal.ac.jp/lingfes/` を作ることはできません。

## 手元で生成・動作確認する場合

```sh
python3 scripts/build_site.py
python3 scripts/validate_site.py
```

生成後は `public/index.html` をブラウザで直接開いても表示できます。ローカルサーバーは不要です。www2へ転送するのは `public/` 内の `.html` と `.css` と（必要に応じて）`.nojekyll` のみです。

## 公開前の確認

- 各募集URL、開催日、募集期間、各室の運用、現地定員・対象者優先枠が決定しているか。
- ブースの重複と現地配信枠の上限が正しいか。**共著者を含め各時間帯1人1件**の制限は応募管理表側で追加確認すること（発表者名の自由入力から機械判定はしません）。
- フェス独自のアンチハラスメントポリシーと、国語研の個人情報保護ポリシーへのリンク・適用範囲を確認。
- 配信時のヘッドセットや音声干渉、講堂の飲食禁止、特別な配慮が必要な方向けの個室利用等は運営上別途確認。
- URLの `/lingfes/` の実配置ディレクトリ・更新経路・権限は国語研Web管理担当が承認。

このサイト自体は申込受付やPDFアップロードを行いません。リンク先の外部サービス（Peatix、Google Forms等）には、そのサービス側の技術要件が適用されます。
