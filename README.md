# 言語学フェス｜www2向け静的Webサイト

本リポジトリの過年度アーカイブは「案A（タイトルのみ保全）」です。案B（発表者情報・ポスターの保全）は別途権利・公開範囲の確認が必要であり、この公開データには含めません。

**GitHubリポジトリ `masayu-a/lingfes` で管理する静的Webサイトのソースです。** 国語研 `https://www2.ninjal.ac.jp/lingfes/` への反映は、国語研のWeb管理担当による承認とサーバーへの配置が必要です。GitHub上の更新とwww2での公開は別工程です。

## 過年度プログラム（タイトル保全）

- **2021〜2026年、計483件の発表番号・題名を収録**。データは `data/archive_titles_2021-2026.json`、読みやすい一覧は `docs/lingfes_titles_2021-2026.md`。
- `scripts/build_site.py` を実行すると、`public/2021/` 〜 `public/2026/` の題名一覧HTMLが再生成されます。www2側ではJavaScriptを使いません。
- 原典URLは各年度のページに記載。**転記誤りの最終照合は未了**です。2021年は原典42タイトルに対し、開催報告で「44件」と記載されているため、差分を未確認として明記しています。
- 2027年の発表枠とは独立した記録です。過年度のPDF、著者や参加者の連絡先は保存していません。

## 重要な仕様

- **www2サーバーへはHTML/CSSのみを配置。JavaScriptファイルも `<script>` タグも一切使用しません。** クライアントの `fetch()` や動的JSON読込も行いません。
- **GitHub上で編集**するのは `src/`（HTML・CSS）と `data/`（JSON）。GitHub Actionsまたは手元のPythonで **公開前に** 静的HTMLを生成します。www2はPythonやJSONを実行・配信しません。
- 2027年の発表データが登録されると、発表地図を **A/B/C それぞれ別HTML**（`2027/map-a.html`, `map-b.html`, `map-c.html`）として生成します。未登録時は公開しません。
- 発表データ登録後に `2027/program.html` を生成します。キーワード検索機能はなく、ブラウザのページ内検索（Ctrl+F）が利用できます。
- 各ブースP01〜P36は、発表登録時に `program.html#A-P01` のような固定アンカーへリンクします。P27〜P30・P33〜P36は国語研現地配信候補です。
- オンライン発表は **36件×3回＝最大108件**。うち国語研からの現地配信は延べ24件まで。3月28日の現地ポスター発表枠は3月27日のA・B・C各36件のうち各12件、計36件とします。
- 個別のサムネイル・発表証明書なし。公開同意のないPDFや応募名簿をこのサイトへ格納しないでください。

## ファイル構成

| `src/index.html` | 恒久トップ `/lingfes/` の公開原稿 |

## GitHub のWeb画面から更新する場合

1. 開催案内や発表募集の文章を修正するには `src/2027/index.html` を開いて鉛筆アイコンから編集しコミット。
2. 申込URLを決めたら `data/site-2027.json` に **https:// ではじまる正式URL** を設定。未確定なら空欄のまま。
3. 発表プログラムは `data/program-2027.json` の `presentations` にエントリーを追加。書式例は `docs/program.sample.json`。`onsite: true` は3月27日の国語研オンサイト配信（各回最大8件、合計24件）、`day2_poster: true` は3月28日の現地ポスター発表（A・B・C各12件）を意味します。別々に指定してください。募集時に集めたPDFはここにアップロードせず、公開許諾を得たURLのみ登録します。
4. `main` ブランチへの変更で GitHub Actions が `scripts/build_site.py` と `scripts/validate_site.py` を実行し、`generate-public.yml` によって生成済み `public/` を必要時にコミットします。GitHub Pagesプレビューは別のワークフローです（有効化した場合）。
5. **www2への反映は別工程**です。国語研側の承認を得た方法で生成済みの `public/` の中身のみを配置します。自動転送ワークフローは初期状態で無効です。

**注意：** GitHub Pagesとwww2のURLは別物です。GitHub PagesのCNAME設定だけで `www2.ninjal.ac.jp/lingfes/` を作ることはできません。

## 手元で生成・動作確認する場合

```sh
python3 scripts/build_site.py
python3 scripts/validate_site.py
```

生成後は `public/index.html` をブラウザで直接開いても表示できます。ローカルサーバーは不要です。www2へ転送するのは `public/` の中身です。`.nojekyll` はwww2側では省略できます。

## 公開前の確認

- 発表申込URL、開催日、募集期間、現地開催条件が決定しているか。
- 将来公開するプログラムのブース重複と現地配信枠の上限が正しいか。**共著者を含め各時間帯1人1件**の制限は応募管理表側で追加確認すること（発表者名の自由入力から機械判定はしません）。
- フェス独自のアンチハラスメントポリシーと、国語研の個人情報保護ポリシーへのリンク・適用範囲を確認。
- 配信時のヘッドセットや音声干渉、講堂の飲食禁止、特別な配慮が必要な方向けの個室利用等は運営上別途確認。
- URLの `/lingfes/` の実配置ディレクトリ・更新経路・権限は国語研Web管理担当が承認。

このサイト自体では申込受付やPDFアップロードは行いません。受付方法は確定した外部サービスに応じてご案内します。

## 2027年のトップページ（最新版）

## 2027年参加募集の3区分（申込・定員を独立管理）

- **2027年3月27日：オンライン参加**。開催約1週間前を目途に申込を締め切る予定。設定キーは `online_participation_url`。
- **2027年3月27日：国語研からのオンサイト配信・参加**。oViceオンライン企画への国語研（講堂・多目的室等）からの参加を人数限定で受付、定員到達時に締切。設定キーは `ninjal_onsite_20270327_url`。居室のある方は居室から参加。
- **2027年3月28日：現地参加のみ**。オンライン参加はなく、3月27日とは別途募集・定員管理。設定キーは `onsite_20270328_url`。
- 3月27日と28日の参加者数は別々に集計します。3月27日の参加申込によって28日の参加は確定しません。
- 参加募集開始の予定は2027年2月8日ごろ（発表の採否案内時）。具体的なURLの確定までは公開ページに申込ボタンは表示されません。
