# 言語学フェス2027　ブース発表選定方法（案）

オンライン発表の各コアタイム（A・B・C）につき、ブース数は36とします。応募が定員を超えた場合、発表内容の優劣によらず、公開数値を用いた抽選でブース割当を決定します。

応募番号はA・B・C通算の受付順で1〜3桁（例：`42`）を発行し、抽選では先頭に0を付けた4桁（例：`0042`）にゼロパディングして扱います。

**同じコアタイムで共著者の一人でも重複している場合**、受付番号が最も大きい（最後の）申込のみをブース抽選の対象とし、それ以前の申込はフェス・ギャラリー（資料展示枠）に移します。異なるコアタイムでの発表はこの制限の対象外です。

不適切な多重申込として事務局がRejectした発表は、ブース抽選およびフェス・ギャラリーの対象外です。Reject対象の申込番号を抽選結果とともに公表します。試験登録は対象外とし、試験用の申込番号は公表しません。

抽選には、**2027年2月2日の日経平均株価の終値**を用います。各抽選対象について、次の形式の文字列をUTF-8でSHA-256に入力します。

```
lingfes2027|A|終値（カンマなし・小数2桁）|受付番号（ゼロ埋め4桁）
```

得られた64桁のハッシュ値を、A・B・Cそれぞれで**昇順**に並べ、上位36件をブース発表に採択します。**37位以降はフェス・ギャラリーの対象**とし、発表者が資料の公開に同意した場合に掲載します。**採択後に辞退が生じても繰上げ採択は行いません。** 同枠内での共著者重複によりブース抽選から外れた発表も、同意があればフェス・ギャラリーの対象です。

使用する終値、抽選の実行条件、匿名化した抽選順位とReject・ギャラリー移動一覧を公開します。
