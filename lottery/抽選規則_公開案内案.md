# 言語学フェス2027：ブース・現地ポスター・現地配信の抽選について

発表申込の締切は、**2027年2月1日（月）正午12:00（日本時間）**です。

抽選には、申込締切当日の**2027年2月1日（月）の日経平均株価の終値**を用います。申込番号はA・B・C通算の受付順に付け、抽選時には4桁のゼロパディングを行います（例：1→0001、12→0012、123→0123）。

## 同じフォームによる新規・修正・取消

発表申込は一つのMicrosoft Formsで新規・修正・取消を受け付けます。修正・取消の際は以前の受付番号と氏名・メールアドレスを記入してください。照合の上、修正の場合は最後の申込だけを有効とし、旧申込は取り消します。本人確認できない場合は事務局から確認します。

同じコアタイム内で一人でも共著者が重なる申込は、最後の申込だけをブース抽選対象とし、それ以前の申込はフェス・ギャラリーの対象とします。異なるコアタイムでの発表は認めます。事務局が不適切な多重申込としてRejectした場合は抽選・ギャラリー双方から除外し、申込番号を公表します。試験登録の申込番号は公開しません。

## 1. 3月27日 オンラインブース（A/B/C各36件）

ブース抽選の対象者について、次の形式のUTF-8文字列をSHA-256で計算します。

```text
lingfes2027|A|終値（カンマなし・小数2桁）|申込番号（4桁）
```

**SHA-256の16進数表記の昇順**で、A・B・Cの各上位36件を採択します。37位以降は、本人が希望した場合、フェス・ギャラリーに提出資料を掲載します。繰上げ採択は行いません。

## 2. 3月28日 現地ポスター（A/B/C各8件）

オンラインブースに採択された発表のうち、現地ポスターを希望したものを対象に各8件を抽選します。主発表者のみが現地ポスター発表者として参加できます。

```text
lingfes2027|POSTER|A|終値|申込番号（4桁）
```

## 3. 3月27日 国語研での現地配信・参加（32席）

主発表者のうち国語研からの現地配信・参加を希望した方を対象に、**主発表者1人につき1席**として扱います。国語研内に居室がある方・実行委員は32席の定員外です。

現地ポスターに採択された主発表者が現地配信・参加も希望した場合は、先に32席の中から割り当てます。その後の残席を次の形式のSHA-256の昇順で決定します。

```text
lingfes2027|ONSITE|終値|代表申込番号（4桁）
```

同一人物が異なる枠に複数の有効申込を持つ場合は、その中の最も小さい申込番号を代表番号とし、席を重複して割り当てません。**現地配信・参加を希望しない方は、現地ポスターに採択されても優先枠の対象になりません。**

計算プログラムと使用した終値、匿名化した抽選結果を公表します。個人情報のある回答原簿や、試験登録・旧申込の内部履歴は公開しません。

*注：一般参加募集で申し込む方を含む現地配信・参加枠の最終的な取扱いは、一般参加募集の案内で確認してください。*
