# 言語学フェス2027：ブース抽選とフェス・ギャラリー振分け

このディレクトリは、言語学フェス2027の抽選プログラムです。`www2` のWebサイト本体とは独立しています。応募者のメールアドレスや著者一覧をリポジトリに置かず、**実行時にのみCSVを読み込む**方式です。

- `lingfes2027_lottery.ipynb`：Google Colab版。先頭の「抽選設定」セルだけ変更して実行できます。
- `lingfes2027_lottery.py`：MacやLinuxで実行するPython版。設定は冒頭に詳しくコメントしています。
- `sample_applications.csv`：架空の応募例。実在の応募情報ではありません。
- `tests/test_lottery.py`：ネット接続不要の単体テスト。
- `requirements.txt`：株価取得ライブラリ。

## 1. まず抽選の規則を固定する

**入力する受付番号はA/B/C枠共通の通算番号**です。申込時は1〜3桁（例：`1`、`12`、`123`）で付与されますが、抽選ではゼロパディングで4桁（`0001`、`0012`、`0123`）にそろえます。A/B/Cごとに番号を振り直しません。

1. `LAST_PRESENTER_ID`（実際の最終受付番号）を入力します。`MAX_APPLICATION_NUMBER` は受付番号の設定上限です。例えば最終申込 `0237` なら `LAST_PRESENTER_ID=237`、上限 `MAX_APPLICATION_NUMBER=500` とします。欠番は構いませんが、**実際の受付CSVにない番号を勝手に補って抽選しません**。
2. `MULTIPLE_APPLICATION_REJECT_IDS` に、事務局が多重申込と判定し**完全にRejectする申込番号**を列挙します。Rejectされた発表はブース抽選・ギャラリー掲載のいずれからも除外します。**その申込番号とReject理由はWeb公開用一覧に出ます。** 多重申込の認定は自動ではなく、事務局が確認したリストに従います。
3. `TEST_REGISTRATION_REJECT_IDS` に、入力テストなどの試験用申込番号を列挙します。抽選から除きますが**公開用HTMLには試験用番号を記載しません**。
4. 同じA/B/C枠の中で、**一人でも共著者が共通する複数の応募**があれば、各著者について申込番号が最後（最大）のものを優先します。より古い応募は**Rejectではなくフェス・ギャラリー**へ移動します。**AとCなど別の枠間では重複可**です。
5. `COAUTHOR_GALLERY_MOVE_IDS` に、手作業の照合によりギャラリーへ移す申込番号を追加できます。自動判定の共著者重複はこのリストに書く必要はありません。この手動指定は後続申込の判定を覆さず、指定された申込をブース抽選から除外します。
6. 残りのブース抽選候補に対し、各A/B/C枠ごとに `lingfes2027|{枠}|{日経平均終値}|{受付番号}` のUTF-8文字列からSHA-256を計算します。終値はカンマ無し小数第2位まで、番号はゼロパディング4桁です。例えば `lingfes2027|A|58123.45|0001` です。
7. **SHA-256を64桁の16進表記の昇順**で並べ、各枠の上位36件をブース採択とします。37位以降は、資料の公開に同意した場合にフェス・ギャラリーへ掲載します。**採択後に辞退が出ても繰上げ採択は行いません。** 同じ枠内の共著者重複によるギャラリー移動も、本人の公開同意が必要です.

※「同一枠内で最後の申込のみ」というルールは、申込番号が受付順に発行されたことを前提とします。同姓同名・表記ゆれを避けるため、著者欄には可能なら**事務局側で付与した一意の著者ID**を入れてください。共著の入れ子関係については、各著者の最も新しい申込がその著者を含む先の申込に優先します。

## 2. 設定例

以下は**動作説明用の架空例**です。実際の番号を指定してください。

```python
MAX_APPLICATION_NUMBER = 500   # 受付上限（0001～0500）
LAST_PRESENTER_ID = 237       # 現在の最終受付ID（0237）
MULTIPLE_APPLICATION_REJECT_IDS = ["0012", "0045"]
COAUTHOR_GALLERY_MOVE_IDS = ["0023"]
TEST_REGISTRATION_REJECT_IDS = ["0001", "0100"]
BOOTH_CAPACITY = 36
INPUT_MODE = "csv"             # デモではなく実際の応募CSVを使用
CSV_PATH = ""                 # Colabの場合、実行時にアップロード
MODE = "auto"
```

番号が両方の手動リストに含まれる、受付CSVにない番号を指定する、最終受付IDを超える、などの不整合があるとプログラムを停止します。誤った条件で抽選しないためです。

## 3. 日経平均株価の取得と予行演習

株価はYahoo Financeの日経平均指数 `^N225` の日次終値から自動取得します。

- `MODE="auto"`：2027年2月2日より前は、直近の**確定した**終値で予行演習。2027年2月2日16時以降は、その日の終値を厳密に要求する本番モードへ切り替えます。
- `MODE="preview"`：日時にかかわらず予行演習をします。
- `MODE="final"`：2027年2月2日の終値が取得できなければ停止します。

本番公開前に、Yahoo Financeで取得した終値を日経公式発表値などと**照合**してください。応募原簿・Rejectリスト・手動移動リスト・抽選手順は、公的な終値が確定する前に固定しておいてください。予行演習で生成されたHTMLには「公開不可」の警告が入ります。

## 4. 応募CSV

```csv
application_no,slot,authors,title
1,A,山田太郎;佐藤花子,言語調査の中間報告
2,C,山田太郎;中村一郎,文法研究の報告
3,A,佐藤花子;田中一郎,調査計画
```

- 列名は英語でも日本語でも読み込み可能です。
- 著者は半角セミコロン `;` で区切ります。
- 受付番号は4桁表記でなくても受け付けますが内部で4桁に統一します。
- 実際の申込CSVには個人情報が含まれる場合があるため、**公開リポジトリへコミットしないでください**。

## 5. Google Colabで実行する

1. `lingfes2027_lottery.ipynb` をGoogle Colabで開きます。
2. 依存パッケージのインストールセルを実行します。
3. **「抽選設定」セル**で最終受付番号と3種類の番号リスト、モードを設定します。
4. 本番では `INPUT_MODE="csv"` とし、CSVをアップロードします。まず `MODE="preview"` で結果を確認します。
5. `ランタイム → すべてのセルを実行` で株価取得・抽選・結果作成を実行します。


## 8. 実行前に確認すること

- 同枠内の共著者重複は「ギャラリー移動」で、**Rejectではない**。
- 定員超過はギャラリー対象とし、**辞退が生じても繰上げ採択しない**。ギャラリー掲載には資料公開への同意が必要。
- 多重Rejectは公表されるため、事務局で理由を確認し、番号と理由のみを公表して問題ないか確認する。
- 公開用に表示する発表題目は `PUBLIC_INCLUDE_TITLES=False` が初期値。正式な公開許諾があるときだけ切り替える。
- 試験登録番号、共著者ID・メールアドレス等は非公開。
- 株価終値、番号の固定、SHA-256昇順、受付原簿の確定について実行記録を保存する。
