# 言語学フェス2027：Microsoft FormsのExcelから行う3段階の抽選

このプログラムは、Microsoft Forms「言語学フェス2027 発表申込フォーム」の回答Excel（`.xlsx`。UTF-8の`.csv`も可）を**そのまま入力**として使います。最新のフォーム（2026年11月22日共有の第7版）は現地配信定員28席です。**実際のForms Excel出力は未確認のため、初回の実データでは列名・選択肢・タイムゾーンを必ず確認してください。**

## 1. 抽選日・締切・定員

| 項目 | 規則 |
|---|---|
| 発表申込締切 | **2027年2月1日（月）正午12:00（日本時間）** |
| 抽選に使う株価 | **同日2月1日（月）の日経平均株価の終値** |
| 本番判定 | 同日16:00 JST以降。終値が自動取得できない場合は停止 |
| 予行演習 | それ以前は直近の確定終値でPREVIEW。任意の架空終値で検証も可能 |
| A・B・Cのオンラインブース | 各36件、合計最大108件 |
| 3月28日現地ポスター | **各8件、合計最大24件**。ブース採択者の希望者から抽選 |
| 3月27日国語研の現地配信 | **最大28席**（主発表者1人あたり1席）。居室あり・実行委員は定員外 |
| 現地配信の対象 | **オンラインブース採択者のうち所内配信を希望する主発表者のみ**。ギャラリー・一般参加のみの方は対象外 |
| 現地配信の優先枠 | 現地ポスター採択者のうち所内配信を希望した主発表者を優先し、**残席をその他のオンラインブース採択者の希望者から抽選** |
| 辞退による繰上げ | **いずれの抽選でも行わない** |

東京証券取引所の現物株式の取引時間は15:30までです。2月1日12:00に申込を締め切った後、同日終値が公開されます。公開数値が判明する前に回答Excel・Rejectリスト・共著重複の手動指定リストを固定してください。株価自動取得元はYahoo Financeの`^N225`で、**本番公表前に日経公式公表値との照合が必要**です。

### SHA-256の計算式

全てUTF-8文字列のSHA-256を計算し、**16進64桁を昇順（小さい順）**に並べます。終値は`58123.45`のようにカンマなし・小数2桁、受付番号は4桁ゼロパディングします。

```
ブース       lingfes2027|A|58123.45|0001
現地ポスター lingfes2027|POSTER|A|58123.45|0001
現地配信     lingfes2027|ONSITE|58123.45|0001
```

`58123.45`は**架空の数値**です。ブースとポスターにはコアタイムA/B/Cを入れます。現地配信は「主発表者1人」を単位とし、同じ主発表者が異なる枠に複数の有効なオンラインブース採択を持つ場合、その人の**最小の採択受付番号**で現地配信ハッシュ値を計算します。同じ人物が複数の抽選券を持たないための規則です。

### 所内配信枠28席の割当順序

1. オンラインブースA/B/Cの各36件を抽選で決定します。
2. そのうちポスター希望者から、3月28日の現地ポスターA/B/C各8件を別抽選します。
3. 3月27日の所内配信を希望する現地ポスター採択者（主発表者）に、28席の範囲内で優先して配信権を付与します。
4. 残席があれば、**その他のオンラインブース採択者で所内配信を希望する主発表者**の中から`ONSITE`ハッシュ値昇順に割り当てます。
5. 国語研内に居室がある方・実行委員は28席に含めず、別扱いとします。一般参加のみの方・フェス・ギャラリー対象者は3月27日の所内配信権の対象外です。

たとえば、ポスター採択者24人の全員が所内配信を希望し、定員外対象者がいなければ、24席を優先付与し、**残る4席**を抽選します。ポスター採択者が所内配信を希望しない場合、その方には優先席を割り当てません。

## 2. Microsoft Formsからの入力方法

1. Microsoft Formsで対象フォームを開き、**「応答（回答） → Excelで開く」**から回答を保存します。
2. 保存した`.xlsx`をGoogle Colabからアップロードするか、Mac/Windowsで`--input`に指定します。
3. **Excelの一行は、一回の送信**です。新規・申込修正・申込取消も同じExcelに含めます。
4. Formsが標準出力する最初の**`ID`列（回答ID）**をA/B/C共通の受付番号とします。`1`→`0001`、`12`→`0012`、`123`→`0123`。取消回答・試験回答で番号が欠けても**再採番しません**。
5. **「完了時刻」列**で締切を検証します。Excel時刻にタイムゾーン情報がない場合は、設定`FORM_EXPORT_TIMEZONE`（初期値`Asia/Tokyo`）で解釈します。初回に実際の回答通知時刻と比較し、UTC記録なら`UTC`に変更してください。
6. `LAST_PRESENTER_ID=0`はExcelの最大回答IDを自動使用します。既知の最終IDを指定すると、Excelに最後の回答が欠けていないか一致検査します。

本プログラムは、フォームの質問タイトルのキーワードを照合して次の列を読みます。質問順・回答列順の変更は問題ありませんが、**質問名を変えた場合は読込対応が必要**になることがあります。

| Formsの設問 | 処理 |
|---|---|
| 主発表者の氏名／メールアドレス | 修正・取消の本人照合、現地配信の人物単位集約。非公開 |
| 手続きの種類 | 新規／申込修正／申込取消 |
| 以前の受付番号（申込修正・申込取消） | 旧回答IDへの照合。メール・氏名の一致が必須 |
| 発表するコアタイム | A/B/Cのいずれか。Excelの長い選択肢でも冒頭の枠名を認識 |
| 発表題目・発表概要・所属 | 内部台帳用。公開希望を得るまで公開しない |
| 共同発表者の氏名（所属）；区切り | `;`で分割し、所属括弧を除いて共著者照合 |
| 共同発表者同意・ポリシー確認 | 「はい」を確認（該当列がある場合） |
| 1日目 所内配信（3択） | いいえ／**28席抽選対象**／居室あり・実行委員で定員外 |
| 2日目 現地ポスター（はい・いいえ） | ブース採択後の各枠8件の抽選対象 |
| フェス・ギャラリーの掲載希望 | 掲載希望を記録。**資料は同意なしで公開しない** |
| ブース抽選に漏れた場合のオンライン参加希望 | 参加案内の内部データとして保持 |
| 次回以降の運営参加希望 | 内部の希望者一覧CSVに出力 |
| 発表資料のアップロード | Excelに列がある場合は参照情報のみ保持。プログラムはファイル本体を公開しない |

**重要：**「すべてのユーザーが回答可能」のMicrosoft Formsでは、ファイルアップロード質問が利用できない制約があります。学外利用者のPDF提出は国語研が許可した別のアップロード方法で確認し、申込締切までの提出完了を別途照合してください。このプログラムはExcel列のファイル名だけを根拠にPDF提出の有効性を判断しません。

## 3. 修正・取消・重複・Rejectの優先順位

1. **試験登録**（`TEST_REGISTRATION_REJECT_IDS`）は完全除外し、番号を公表しません。
2. **事務局による多重申込Reject**（`MULTIPLE_APPLICATION_REJECT_IDS`）はブース・ギャラリーの両方から除外し、番号を公開します。
3. **締切後**の回答は除外します。締切後の取消は過去の有効回答を取り消しません。
4. **申込修正**は新回答IDで受付。旧IDの主発表者氏名・メールアドレスが一致し旧IDが現役であるときだけ旧申込を「修正済み」にします。修正前の応募はギャラリー対象外です。
5. **申込取消**は同じ照合後に旧申込を取り消します。取消依頼自体はブース抽選対象外です。
6. **同一コアタイムの共著者重複**は、最後の有効申込だけブース抽選へ、以前の申込はギャラリー候補へ。**発表枠が余っていても同一コアタイム内で共著者が重なる発表はブース採択1件のみ**です。異なる枠間の重複は許可します。
7. 事務局による手動ギャラリー指定（`COAUTHOR_GALLERY_MOVE_IDS`）も抽選から外します。
8. 残りの申込だけでブース抽選を行います。ブース非採択・共著者重複の資料公開は、ギャラリー掲載希望を回答した場合に限ります。

同姓同名・改姓・所属表記の違いは自動で確定できません。共著者の機械判定結果を本番前に人手で確認し、必要なら事務局の手動指定を使ってください。**本人確認を満たさない修正・取消は、勝手に処理せずエラー停止**します。既に修正済みの旧番号を指定する操作もエラーにします。

## 4. 3種類の抽選

- **ブース抽選：**各枠の有効申込をSHA-256昇順に並べた上位36件。37位以降はギャラリー候補。繰上げはありません。
- **現地ポスター抽選：**ブース採択者かつQ14の希望者のみで、各枠SHA-256昇順の上位8件。ポスター採択を理由にオンラインブースの順位は変更しません。
- **所内配信抽選：**フォームでQ13に「はい」と回答し、かつ**オンラインブースに採択された主発表者**を対象とし、同一人物のA/B/C応募を1人にまとめます。居室あり・実行委員は28席の定員外です。残る希望者のうち現地ポスター採択者を先に割り当て、28席の残席を`ONSITE`ハッシュの昇順で決めます。Q13が「いいえ」の方には優先席も割り当てません。

**一般参加募集との関係：**この28席は3月27日の**オンラインブース採択済みの主発表者用**です。ギャラリー対象者や2月8日以降の一般参加申込者は含みません。一般参加のみの方が国語研所内から現地参加できるのは**3月28日（日）のみ**です。

## 5. Colabで実行

`lingfes2027_lottery.ipynb`をGoogle Colabで開き、上からセルを実行します。最初のセルが`yfinance`と`openpyxl`をインストールし、次のセルでPythonコードを生成します。設定セルで手動除外IDと最終IDを指定し、Formsからダウンロードした**回答Excelファイルを1個だけ**アップロードしてください。

## 6. Mac/Windowsで実行

```sh
python -m pip install -r lottery/requirements.txt
python lottery/lingfes2027_lottery.py --input "言語学フェス2027 発表申込フォーム.xlsx" --mode auto
```

終値がまだ判明していない段階の検証は、架空の終値を指定できます。

```sh
python lottery/lingfes2027_lottery.py --input "回答.xlsx" --mode preview --preview-close 58123.45
```

テストはネット接続なしで実行できます。

```sh
python -m unittest discover -s lottery/tests -v
```

## 7. 結果の保存と公開

実行結果は`lingfes2027_lottery_results/`に保存されます。

- **`internal_private/`：**全履歴、氏名・メール、ブース順位、ポスター順位、現地配信順位、試験登録、Reject、修正取消、運営参加希望、監査用条件など。**絶対にGitHubへ置かないこと。**
- **`web_public/`：**個人名を含まない`index.html`、ブース／ポスター／現地配信の匿名順位CSV、多重Reject番号、ギャラリー対象番号、抽選条件JSON。**本番と照合し、事務局が承認した場合だけ**公開。

結果を自動で`main/public/`へ混ぜないでください。既存の`mirror-new2.sh`と`publish_gate.py`を使う場合は、**事務局の本番承認後に限り、抽選専用ディレクトリへ同期**してください。実データや試験用ExcelをWebに置くことはありません。

## 8. GitHubのWindows Web画面から更新する場合

ZIP内の**同じパスにあるソースファイル**を`main`ブランチへ上書きします。`src/2027/index.html`は案内、`lottery/`以下は抽選プログラムです。`main`の更新後、GitHub Actionsが`public/`を生成します。`lottery`ブランチも保守するなら同じ`lottery/`ソースを反映してください。`web_public/`は実行結果なので**今はGitHubへ登録しません**。
