# 言語学フェス2027 ブース抽選（Google Colab）

`lingfes2027_lottery.ipynb` を Google Colab で開き、上から順番にセルを実行します。Macで動かす場合は `lingfes2027_lottery.py` を使用できます。外部への情報送信は、日経平均株価を取得するための問い合わせだけで、応募一覧をYahoo Finance等へ送信しません。

## 抽選のルール

- 申込番号は全枠共通・受付順の通算番号で、4桁にゼロパディングします（`0001`〜`9999`）。
- A/B/Cはそれぞれ独立した枠です。**同じ枠**で共著者の一人でも重複したら、後の申込番号（数値が大きいもの）を残し、古い申込全体を無効とします。**AとCの両方**に共通著者がいても相互に無効にはしません。Bとも同様です。
- 候補者ごとに `lingfes2027|{枠}|{日経平均終値2桁}|{申込番号4桁}` をUTF-8でSHA-256にかけ、各枠で**ハッシュ値昇順**に並べます。ブース数は各枠36件。超過分は繰上げ・フェス・ギャラリー候補になります。
- 同一申込の著者欄は `山田太郎;佐藤花子` のように半角セミコロン `;` で区切ってください。名前の揺れ・同姓同名を機械的に完璧に判別することはできないため、正式運用では内部の著者IDを使うことを推奨します。
- すべての応募に、**受付順に単調増加**する番号を付けてください（CSV行の順番ではありません）。番号の再利用・振り直しは禁止。

## 終値の使い方

- `MODE="auto"`（初期値）：**2027年2月2日（火）より前**は直近の確定した日経平均終値で予行演習。取引日の日本時間16:00以降は当日値を採用できる場合に採用。16:00より前または休場日なら直近取引日の終値に戻ります。終値の配信が遅れている場合も前営業日のデータになるため、プログラムは実際に使った日付を明記します。
- **2027年2月2日の16:00（日本時間）以降**は `MODE="auto"` が本番用終値を厳密に要求し、その日付のデータがなければ停止します。本番に実行する際は、この日までに応募対象リストと採否条件を固定してください。
- `MODE="preview"` はいつでも予行演習、`MODE="final"` は指定日の本番抽選のみ。
- Yahoo Financeのシンボル `^N225` を `yfinance` で取得します。Yahoo Financeの配信値は公式の最終値と照合し、抽選に採用した日付・金額を記録してください。
- 抽選規則に株価の日付そのものは含みません（指定された4フィールドに忠実な実装）。ただし、記録用メタデータには採用日時を残します。

## Google Colabで動かす

1. Google Colab (https://colab.research.google.com/) で `.ipynb` を開きます。
2. 先頭のインストールセルを実行します。
3. 設定セルで `MAX_APPLICATION_NUMBER = 150` の数値を変更します。
4. 予行演習なら `INPUT_MODE="demo"`、実際のCSVを使うなら `INPUT_MODE="csv"` に設定します。後者で `CSV_PATH=""` の場合は実行時にアップロードダイアログが出ます。
5. 実行セルを実行すると日経平均終値を自動取得し、抽選順位を画面に表示し、結果ZIPをダウンロードします。

## 実際の応募CSV形式

サンプルは `sample_applications.csv` です。列は次の形式（日本語の別名も認識します）。

```csv
application_no,slot,authors,title
1,A,山田太郎;佐藤花子,調査報告
2,C,山田太郎;中村一郎,別の調査報告
3,A,佐藤花子;田中一郎,再申込
```

上記では `0001` は同枠Aの `0003` と著者が重なるため無効、`0002` はC枠なので有効です。作者情報がフォームから取得できない場合は、まず応募者名・共著者名または著者ID一覧を作成してください。

## 出力内容

実行後 `lingfes2027_lottery_results/` に次のファイルが作られます。

- `抽選順位_内部用.csv`：有効応募の全順位・著者名・ハッシュ元文字列
- `ブース割当候補.csv`：各枠の上位36件
- `ギャラリー・繰上げ候補.csv`：各枠の37位以降
- `無効申込_内部用.csv`：同枠の共著者重複によって無効となった申込と理由
- `抽選検証用_匿名.csv`：著者名を含めない検証用の全順位
- `抽選実行条件.json`：株価日・終値・抽選規則・実行日時・原簿のハッシュ

※ 個人情報を含むCSVや応募者情報は、非公開リポジトリであっても必要な権限を確認して保管してください。出力はGitHubに自動コミットされません。

```bash
python3 -m pip install yfinance pandas

```
